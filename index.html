    What this demonstrates

    Command

    A SiLA client requests a goal such as MoveToPose or SetLiftHeight. It does not stream motor setpoints.

    Property

    The server reports values such as EquipmentState, CurrentPose, and LiftPosition.

    Controller boundary

    The robot controller, drive, PLC, and safety system remain responsible for deterministic motion and interlocks.

    Built as a local learning tool. No data is collected or transmitted.
