# SiLA Robot Lab

A clean, offline learning simulator that shows where SiLA 2 fits in a robot and lift application.

## What it demonstrates

- High-level robot pose commands
- Lift position commands and properties
- Guard and drive safety interlocks
- A guided pick, lift, place, and home workflow
- A readable SiLA command and property activity log
- The boundary between SiLA orchestration and real-time machine control

## Run locally

Open `index.html` in a modern web browser. No build step, server, account, or internet connection is required.

## Privacy

The application contains no personal data, analytics, tracking, remote requests, or persistent storage.

## Scope

This is an educational simulation. It does not implement a SiLA server and must not be used to control physical equipment.
